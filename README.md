# 交易业务异常诊断 Agent：共享规格仓库

本仓库保存 AgentScope 与 LangGraph 两个实现共同遵循的产品需求和智能体评测标准。这里只维护规格，不存放任何框架实现代码。

## 文档入口

- [产品需求文档（PRD）](docs/PRD.md)
- [智能体评测规范](docs/EVALUATION_SPEC.md)

## 协作约定

1. 需求和评测标准先修改本仓库，再开始对应实现。
2. 两个实现仓库应固定引用本仓库的具体 Git commit，不以“最新版本”作为隐式依赖。
3. 同一评测案例、初始数据、标准答案和评分规则必须对两个框架保持一致。
4. 每次变更记录版本、变更内容、原因及受影响的验收项。
5. 当前阶段只做需求与评测设计；未经明确验收，不把草案描述为已实现能力或已通过的测试。

## 当前状态

- 规格版本：0.1.0-draft
- 项目阶段：需求与评测设计
- 当前范围：PRD 与评测规范
- 暂不包含：业务实现、自动评分器、大规模评测集和生产系统接入
